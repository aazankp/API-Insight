# Screenshots Directory

This folder is designated for UI screenshots demonstrating the **ApiMonitor** web application and operational workflows.

## 📌 Usage Instructions

1. Consult [`../docs/screenshots-needed.md`](../docs/screenshots-needed.md) for the exact list of required screenshots, target URLs, and UI views.
2. Follow all privacy and sanitization rules before saving:
   - Redact all personal emails and employee identifiers.
   - Mask API keys, tokens, and authorization credentials.
   - Use generic or mock target URLs (`api.example.com`).
   - Obscure confidential customer records and proprietary business data.
3. Save screenshots as PNG files using the descriptive names specified in [`screenshots-needed.md`](../docs/screenshots-needed.md).
